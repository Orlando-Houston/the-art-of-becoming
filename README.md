# The Art of Becoming · v3

Personal portfolio for Altun Keskin.

- `index.html`: main one-page personal site (no portrait needed).
- `style.css`: responsive visual style.
- `script.js`: story cards and reading modal.
- Stories of Light and Shadow is the **literary section**, not the website name.
- The linked Cloud Data Center GitHub repository is verified as accessible from the connected account.
- Other projects are labeled as works in progress until verified public links are available.
- Sample fiction is marked as fiction; childhood memories are placeholders, not invented autobiographical scenes.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
Upload the files to a public GitHub repository, then in Settings > Pages select **Deploy from a branch**, `main`, and `/ (root)`. GitHub publishing requires the account holder's appropriate permission.
