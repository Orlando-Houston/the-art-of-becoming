02 · SALESFORCE APPLICATION DESIGN

Accounting Services Application (ASA)

The project. A Salesforce application designed around the relationships between services, clients and consultants, with an emphasis on reliable business data and useful automation.

Architecture & features

  • Custom objects for Service, Client, Consultant relationships, Location and management records
  • Junction objects for service-to-client and service-to-consultant relationships
  • Validation and duplicate rules to improve data quality
  • Address verification integration using Smarty
  • Notifications and error-logging concepts for operational visibility

What this demonstrates

Salesforce data modeling, declarative automation, application architecture and integration planning. Screenshots, code links and testing evidence can be added as the case study is documented.

Concepts covered
